# Blog Customizer

## Описание проекта

Blog Customizer — это интерактивное веб-приложение для кастомизации внешнего вида статьи блога. Пользователь может в реальном времени изменять шрифт, размер текста, цвет текста, ширину контента и цвет фона статьи через удобную форму. Приложение демонстрирует возможности динамического стилинга с использованием CSS-переменных и современных технологий фронтенд-разработки.

## Что прикольного

- **Реал-тайм кастомизация**: Изменения применяются мгновенно без перезагрузки страницы благодаря CSS-переменным.
- **Модульная архитектура**: Компоненты организованы в отдельные модули с SCSS-модулями для изоляции стилей.
- **UI-библиотека**: Собственная библиотека переиспользуемых компонентов (Button, Select, RadioGroup и др.) с Storybook для демонстрации.
- **TypeScript**: Полная типизация для надежности и лучшей разработческой опыт.
- **E2E-тесты**: Автоматизированные тесты с Playwright для проверки функциональности.
- **Современный стек**: Webpack для сборки, SASS для стилей, ESLint и Prettier для качества кода.

## Как запустить

### Предварительные требования

- Node.js
- npm или yarn

### Установка зависимостей

```bash
npm install
```

### Запуск в режиме разработки

```bash
npm start
```

Приложение будет доступно по адресу `http://localhost:3000`.

### Сборка для продакшена

```bash
npm run build
```

### Запуск Storybook

```bash
npm run storybook
```

Storybook будет доступен по адресу `http://localhost:6006`.

### Запуск тестов

```bash
npm test
```

### Линтинг и форматирование

```bash
npm run lint          # Проверка ESLint
npm run lint:fix      # Исправление ошибок ESLint
npm run stylelint     # Проверка Stylelint
npm run stylelint:fix # Исправление ошибок Stylelint
npm run format        # Форматирование с Prettier
```

## Структура проекта

- `src/components/` — React-компоненты (Article, ArticleParamsForm)
- `src/ui/` — Библиотека UI-компонентов
- `src/constants/` — Константы и типы
- `src/styles/` — Глобальные стили
- `webpack/` — Конфигурация Webpack
- `public/` — Статические файлы
